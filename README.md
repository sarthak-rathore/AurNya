# AurNya — Botanical Fine Jewellery E-Commerce

AurNya is a luxury direct-to-consumer jewellery storefront built with **Next.js 14**, **TypeScript**, **Tailwind CSS**, and **PostgreSQL (Drizzle ORM)**.

---

## 🌟 Phases Progress

- ✅ **Phase 1: Prototype** — Storefront look & feel, botanical packaging palettes, and initial product designs.
- ✅ **Phase 2: Real Foundation** — Next.js App Router, SSR, Cart Drawer, Policy pages, and Semantic SEO (JSON-LD).
- ✅ **Phase 3: Database** — PostgreSQL with Drizzle ORM, schema migrations, seeds, and catalog search.
- ✅ **Phase 4: Accounts** — User authentication, JWT sessions, saved addresses, wishlist, and profile management.
- ✅ **Phase 5: Checkout & Orders + Tanishq Luxury Experience** — Complete Checkout with Razorpay/COD, order tracking, webhook verification, PIN code checker, rotating logo loader, and Tanishq-style luxury account portal & plum footer.
- ⏳ **Phase 6: Admin Dashboard** — In progress.
- ⏳ **Phase 7: Polish & Launch** — 3D interactive Mol* views, performance tuning, and launch.

## 🛠️ Tech Stack & Architecture

- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS (Royal Maroon `#832729`, Plum `#250a0e`, Gold `#e5c158`, Ivory `#fcfbf9`)
- **Database**: PostgreSQL with Drizzle ORM + In-Memory Fallback
- **Payments**: Razorpay Node.js SDK & Cash on Delivery (COD)
- **Testing**: Node.js Native Test Runner (`tsx --test`) — 147 test cases passing
